# Models

This category was split into four standalone categories:

- [Closed Models](../closed-models/readme.md) — Proprietary models available via hosted APIs.
- [Decision Models](../decision-models/readme.md) — Non-generative models that return choices, probabilities, and scores for machine decisions.
- [Open Weight Models](../open-weight-models/readme.md) — Models with publicly released weights for self-hosting and fine-tuning.
- [Small Models](../small-models/readme.md) — Compact models for edge, local, and resource-constrained use.
